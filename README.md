# 习 · 论语

帮助读者循序学习《论语》的移动端适配网页 App，目前包含《学而》第一篇全部 16 章。

## 使用

下载仓库后，用现代浏览器打开 `index.html`。无需安装依赖或构建。

## 功能

- 逐章阅读原文、字词注释、白话解读与理解练习。
- 按原文、标题和章号搜索。
- 学习进度、笔记和分章草稿保存在当前浏览器。
- 导出 Markdown 笔记。
- 兼容最初三章版本的学习进度迁移。

## 内容与数据

原文校对来源：[维基文库《论语·学而第一》](https://zh.wikisource.org/w/index.php?title=論語/學而第一&oldid=2058123)。古代原文属于公有领域；标题、注释、白话解读和练习为本项目编写稿，尚待专业校订。

数据仅保存在当前浏览器，不含账户或云同步。换浏览器、换访问地址或清除浏览器数据后，原有进度可能不可用；重要笔记请导出保存。当前为网页版，未打包为 iOS 或 Android 安装应用。

## 验证

已用浏览器测试课程完成、笔记保存和重新打开恢复、导出、搜索、分章草稿、旧数据迁移及 320px 宽度布局。
